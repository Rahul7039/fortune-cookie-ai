## Run it

```sh
python3 main.py
```

It writes the fortune — and nothing else — to `/output/entry.txt` and prints it.

## About

Built for the make.fun competition "Fortune Cookie for an AI Agent": a single line of at most 140 characters, in the voice of a fortune slip, funny and original.
